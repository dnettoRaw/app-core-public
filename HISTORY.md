# Reconstructed project history

AppCore began as local development before this public Git repository existed.
The original workstation and its filesystem timestamps were lost after water
damage. A professional recovery restored partial project files, but the
recovered files received restoration-time timestamps and there was no earlier
Git repository from which to recover commit objects.

The early commits in this public mirror therefore record approximate,
month-level development milestones reconstructed by the maintainer. Their
commit messages use the `history(reconstructed)` prefix, and their dates should
not be read as exact original edit or commit timestamps. They preserve the
reported order and duration of the work without claiming to be the lost Git
history.

The source currently present under `crates/` is not reconstructed: each
directory is extracted from a version published on crates.io. Exact archive
versions and SHA-256 checksums are listed in [`RELEASES.md`](RELEASES.md).
