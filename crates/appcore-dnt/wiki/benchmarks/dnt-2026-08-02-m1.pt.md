# Benchmark DNT: Apple M1, 2026-08-02

Status: evidencia local observada para a ancestralidade do commit no momento da
execucao. Nao e uma certificacao multiplataforma e deve ser regenerada no
hardware do deployment.

## Ambiente

- Comando: `cargo run --release -p appcore-dnt --example compare`.
- Hardware: MacBook Pro `MacBookPro17,1`, Apple M1, 8 cores, 16 GB de RAM.
- SO/kernel: macOS, Darwin 27.0.0, aarch64.
- Storage: armazenamento interno de estado solido, APFS.
- Energia: alimentacao AC, bateria carregada.
- Rust: `rustc 1.97.1 (8bab26f4f 2026-07-14)`.
- Cargo: profile release, features padrao.
- Execucao: uma thread; 20 operacoes de aquecimento para cada caminho.
- Amostras: 200 para read/open; 100 para seal/rekey.
- Cache de leitura: aquecido. Os resultados nao medem I/O duravel nem cache frio.
- Tempo de CPU, pico de RSS e alocacoes por operacao: nao medidos.

O throughput abaixo usa bytes semanticos de plaintext. Portanto, o throughput
compacto representa o payload util retornado, nao os bytes cifrados lidos do
disco.

## Interpretacao

A leitura de plaintext serve apenas como baseline de desempenho. Ela nao
oferece confidencialidade, autenticidade AEAD, metadata de roteamento
autenticada, vinculo com application e tenant, rotacao de chaves ou migracao
versionada do DNT.

O JSON compacto foi mais rapido que o DNT normal nesta execucao porque a
compressao reduziu os bytes processados por XChaCha20-Poly1305 e pelo digest
com chave de aproximadamente 1 MiB para aproximadamente 4 KiB. Inflar o
resultado custou menos que autenticar o ciphertext adicional. Isso depende dos
dados e nao e uma garantia geral de compressao: o binario incompressivel ficou
ligeiramente maior e mais lento, enquanto o segredo pequeno pagou apenas o
overhead do wrapper.

O DNT normal continua sendo o padrao. O modo compacto e apropriado somente
depois que o chamador considerar entropia do payload, vazamento de tamanho e
limites de descompressao. O p95 de open normal V1 para 1 MiB, de 5,80 ms nesta
maquina, fica abaixo do alvo inicial de 10 ms para desktop, mas nenhuma
conclusao e feita para Raspberry Pi, Windows, Linux, cold storage, concorrencia
ou I/O duravel.
