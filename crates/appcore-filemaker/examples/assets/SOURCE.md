# Example font provenance

`NotoSans-Regular.ttf` is the unmodified hinted Noto Sans Regular font from
the official `notofonts/noto-fonts` repository at commit
`ffebf8c1ee449e544955a7e813c54f9b73848eac`:

```text
hinted/ttf/NotoSans/NotoSans-Regular.ttf
SHA-256 b85c38ecea8a7cfb39c24e395a4007474fa5a4fc864f6ee33309eb4948d232d5
```

The font is distributed under the SIL Open Font License 1.1 copied in
`OFL-1.1.txt`. It is used only to keep the public FileMaker examples explicit,
portable, and independent from operating-system font discovery.
