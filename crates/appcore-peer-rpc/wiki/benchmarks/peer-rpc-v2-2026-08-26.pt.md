1.97.1, no commit `8d26cc3927837aeff8ee67bb354439f52c623e74`.

| Pico RSS da suíte completa | 366.432 KiB | ≤ 786.432 |

O caso de 64 MiB possui uma amostra release-profile; seu p99 é essa amostra e
certifica o limite rígido, não uma distribuição populacional de latência. O RSS
inclui casos de Runtime, outbox, Gateway, HTTP, Peer RPC e Scheduler. Testes
focados de codec, registro, autenticação, cancelamento e round trip client/host
de 2 MiB complementam o gate.

```bash
cargo run --release -p appcore-certification -- \
  bottlenecks builds/certification/ac006-bottlenecks.json
```

Esta evidência certifica a linha de desenvolvimento pós-1.0. Ela não publica V2
nem o habilita em host V1.
