La certification release-profile avec source propre a réussi sur macOS/aarch64,
Rust 1.97.1, au commit `8d26cc3927837aeff8ee67bb354439f52c623e74`.

| Observation | Résultat | Gate |
|---|---:|---:|
| Payload décodé incompressible | 67 108 864 octets | exact |
| Chunks | 1 024 | exact |
| Plus grand chunk encodé | 65 536 octets | ≤ 98 304 |
| Plus grande frame JSON | 87 660 octets | ≤ 163 840 |
| Plus grande écriture sink | 65 536 octets | ≤ 65 536 |
| P99 round trip | 1 092 320 834 ns | ≤ 10 000 000 000 |
| Pic RSS de la suite complète | 366 432 KiB | ≤ 786 432 |

Le cas 64 MiB comporte un échantillon release-profile; son p99 est cet
échantillon et certifie la borne dure, pas une distribution de latence. Le RSS
inclut Runtime, outbox, Gateway, HTTP, Peer RPC et Scheduler. Les tests ciblés
du codec, registre, authentification, annulation et round trip client/host de
2 MiB complètent ce gate.

```bash
cargo run --release -p appcore-certification -- \
  bottlenecks builds/certification/ac006-bottlenecks.json
```

Cette preuve certifie la ligne de développement post-1.0. Elle ne publie pas V2
et ne l'active pas sur un host V1.
