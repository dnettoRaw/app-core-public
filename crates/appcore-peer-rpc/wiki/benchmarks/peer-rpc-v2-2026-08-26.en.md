Clean-source release-profile certification passed on macOS/aarch64 with Rust
1.97.1 at source commit `8d26cc3927837aeff8ee67bb354439f52c623e74`.

| Observation | Result | Gate |
|---|---:|---:|
| Incompressible decoded payload | 67,108,864 bytes | exact |
| Chunks | 1,024 | exact |
| Largest encoded chunk | 65,536 bytes | ≤ 98,304 |
| Largest JSON frame | 87,660 bytes | ≤ 163,840 |
| Largest sink write | 65,536 bytes | ≤ 65,536 |
| Round-trip p99 | 1,092,320,834 ns | ≤ 10,000,000,000 |
| Whole-suite peak RSS | 366,432 KiB | ≤ 786,432 |

The 64 MiB case has one release-profile sample, so its p99 equals that sample;
it certifies the hard bound, not a population latency claim. The whole-suite
RSS includes Runtime, outbox, Gateway, HTTP, Peer RPC and Scheduler cases.
Focused codec, registry, authentication, cancellation and 2 MiB client/host
round-trip tests complement this performance gate.

```bash
cargo run --release -p appcore-certification -- \
  bottlenecks builds/certification/ac006-bottlenecks.json
```

This evidence certifies the post-1.0 development line. It does not publish V2
or enable it on a V1 host.
